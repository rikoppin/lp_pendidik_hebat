# Folder Images

## Foto Pembicara

Simpan foto pembicara dengan nama file:
- **speaker-taufik-kasturi.jpg** atau **speaker-taufik-kasturi.png**

### Spesifikasi Foto:
- Format: JPG atau PNG
- Dimensi yang disarankan: 400x400 px (rasio 1:1)
- Ukuran file: maksimal 500KB untuk performa optimal
- Background: sebaiknya menggunakan background netral atau foto formal

### Lokasi File:
```
public/images/speaker-taufik-kasturi.jpg
```

Foto ini akan ditampilkan di section Narasumber pada landing page.
